# Клевер Декор

Адаптивный статический сайт студии декоративной отделки.

## Что обновлено

- Полностью адаптивная верстка для мобильных, планшетов и десктопов.
- Рабочее мобильное меню с доступными ARIA-атрибутами.
- Унифицированы шапка, навигация и подвал на всех страницах.
- Убраны неиспользуемые зависимости от Bootstrap и отсутствующие CSS-файлы.
- Исправлены пути к ресурсам: сайт можно открывать локально и размещать на GitHub Pages.
- Добавлены семантическая HTML-разметка, meta description, lazy loading изображений и телефонная ссылка.
- Добавлено доступное модальное увеличение образцов фактур.
- Улучшена структура страниц «Цены», «Сотрудничество» и «Контакты».

## Запуск

Откройте `index.html` в браузере или запустите локальный сервер из корня проекта:

```bash
python3 -m http.server 8080
```

После этого сайт будет доступен по адресу `http://localhost:8080`.
